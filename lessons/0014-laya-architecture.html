🔬 Laya 架构拆解：一台 33 毫秒的答题机

lesson 0014 专题 · 架构深挖 承接 lesson 0013

主人追问："从 Laya 看起，架构是什么？"——Jev 闭源，Laya 是 Apache 2.0 全开源的那个，所以能真拆到骨头。一句话总览：双向编码器 + 决策头 + 路由器 三件套，没有解码循环，没有生成。

二、答题机制：选项标记（Option Markers）

一次请求被拼成"一张考卷"：状态文本（邮件 / 工单 / JSON）+ 问题（instructions + criteria），每个候选选项旁挂一个自己的 [MASK] 打分位。

流程：一次前向读完整张卷子 → 决策头在每个 [MASK] 位读出一个分数（logit）→ 同一题的选项们做 softmax → 概率分布。

不是"写字"，而是"在每道题的答题框里填把握分"：

  • choice：billing 0.94 / technical 0.03 / sales 0.03 …
  • score：期望分 1.84 / 2.0 + 完整分布
  • noul：P(真) = 0.892

关键设计：选项空间是请求时定义的，不是训练时定死的类别——换 schema、加新选项，不用重新训练。传统分类器做不到这一点（改类别就得重训）。

预算分割（context bifurcation）：上下文被切成"选项预算" head_max_len + "状态预算"：

  • 英文：512 总长 = 选项 192 + 状态约 320
  • 多语：1024 总长 = 选项 256 + 状态约 768

三、为什么能 33 毫秒

  • 没有解码循环：不存在"逐 token 生成 + KV Cache"那套，一次前向把一整张卷子算完
  • 双向编码器：注意力里没有因果 mask，所有 token 互相可见——"理解题"不需要方向性
  • 批量友好：一次调用里的所有问题共享一次前向（10 题 72.3ms = 7.2ms/题，T4）

四、训练：RLCD = 严格真评分规则 + REINFORCE

奖励不是"人类喜欢"（RLHF），也不是"答案可验证"（RLVR），而是严格真评分规则（strictly proper scoring rule）：

赌局类比：模型对每个选项"押注"一个概率分布，庄家用真实结果结算。虚张声势（说 100% 却错）和过度保守都会亏——只有如实报告自己的真实概率，期望收益才最高。这就是"说 90% 就真是 90%"的来源：不是营销词，是奖励函数设计的直接后果。

  • 具体规则：log 分 + 球面分（spherical）；ordinal 打分题另加等级概率分（RPS）
  • 探索：logits 上加零均值高斯噪声
  • 更新：REINFORCE + 组均值基线（GRPO 式——和 lesson 0007 学的 GRPO 同源）
  • 多轮对话：TD(λ=1.0) 在"前缀切片"上回传

五、校准：概率要"诚"，还要"准"

出厂 checkpoint 是过度自信的：需要按（题型 × 选项数）在自有数据上拟合一个温度，把 ECE（期望校准误差）压下来：

模型拟合前 ECE拟合后 ECE
laya（英文）0.4660.081
laya-multilingual0.3140.106

ECE 0.081 ≈ 平均而言，模型报出的概率和实际频率只差约 8 个百分点。同一张对比表里 Jev 的 ECE 是 0.246。校准后的置信度才能用来做"自动放行 / 转人工"的闸门。

六、Router：为什么路由必须在模型外做

英文 checkpoint 看高棉语：准确率 0.000，置信度 0.952——"自信地全错"。置信度闸门救不了（它偏偏很有自信），所以路由必须在推理之前用非模型手段完成：纯 Python 检测 Unicode 字符集 / 语言（<0.5ms），再分发到对应 checkpoint。

生产坑：默认 max_loaded=1，中英交替流量会在每次请求重建模型（CPU 中位 7.4s / T4 10.3s 的重载）；Router(preload=True) 预加载后 → 32.8ms。

八、和已学内容的连接

  • 因果 mask（阶段2 注意力笔记）：LLM 只能看左边（生成需要）；这里双向互见——"理解题"不需要方向性
  • KV Cache / 逐 token 解码（lesson 0001、0005）：整个解码循环被删掉，一次前向 = 全部答案
  • softmax：同题选项间的归一化——把"分数"变成"概率"
  • GRPO（lesson 0007）：RLCD 的更新用 REINFORCE + 组均值基线，就是 GRPO 那一支
  • 温度（lesson 0010）：同一个旋钮，LLM 用它调"随机性"，Laya 用它调"校准"（ECE 0.466 → 0.081）

九、一行总结

答案

Laya = 把"分类器"的骨头（双向编码器 + 打分 + softmax）装上"现代 LLM 的肌肉"（大参数量、RL 训练、校准概率），再用一次前向换掉整个生成循环——所以快得不讲道理；但它也只干一件事：答题。选项是请求时现写的、概率是训练出来的、路由在推理前就定了。
