🎛️ LLM API 参数全景

lesson 0011 阶段 5 — 应用侧 · 一次调用的完整面板

前面学了"怎么想"（采样/温度），这课把一张 API 请求里所有常用参数串成全景： 管怎么想、管怎么输出、管怎么干活，外加一两个不注意就踩坑的工程细节。

一、生成旋钮：决定"每个词怎么选"

参数含义默认备注
temperature采样温度（偏心骰子）1.0思考模式不生效（见 lesson 0010）
top_p累计概率阈值，砍长尾1.0与温度建议只调一个
top_k只保留前 K 个词视实现托管大模型 API 少见
max_tokens回答最大长度视模型⚠️ 思考链 token 也算额度

实测踩坑：思考模式下 max_tokens=300 → 思考内容（约 882 字符）把额度吃光， 最终答案 content 为空。教训：思考模式下把 max_tokens 拉高（≥4096）， 否则你以为模型没回答，其实它把额度全花在"想"上了。

二、惩罚三兄弟：防"复读机"

参数机制DeepSeek 状态
frequency_penalty按词出现次数惩罚，越重复越压低❌ deprecated（无效）
presence_penalty按词是否出现过惩罚，鼓励新词❌ deprecated（无效）
repetition_penalty更强的重复惩罚本地推理常用，托管少见

区别一句话：frequency 看"你说了几遍"，presence 看"你说没说过"。

三、输出控制：决定"长什么样"

参数作用
stop遇到指定序列就停下（如 ``` 或分隔符）
response_format强制输出格式（json_object / json_schema）
stream流式输出：打字机式逐字返回，默认 false 全量等待

四、思考与工具：决定"怎么干活"

参数作用备注
thinking思考模式开关V4 默认 enabled
reasoning_effort思考强度：low / high / max默认 high；medium、xhigh 映射为 high
tools / tool_choice工具清单 + 使用策略auto / required / none
logprobs返回每个词的对数概率诊断"模型为什么这么想"

五、工程细节：不看会吃亏

参数作用注意
messages / system上下文 + 角色设定system 是"你是谁"
user_id标识用户身份用于 KV Cache 隔离：用户间缓存不串
seed固定随机种子，可复现⚠️ DeepSeek 不提供

六、一次完整调用长什么样

示例（DeepSeek 实测结构）
model:        deepseek-v4-flash
messages:     [system=你是Fairy, user=给主人讲历史]
thinking:     enabled + reasoning_effort=high
max_tokens:   4096    ← 思考模式必须拉高
temperature:  1.0     ← 思考模式下传了也不生效
stream:       true

七、一行总结

答案

参数面板 = 生成旋钮（温度/top_p/长度）+ 输出格式（stop/format/stream）+ 干活能力（tools/思考强度）+ 运维细节（user_id/seed）； 改哪一个，取决于你想要模型更随性、更准确、还是更听话。
