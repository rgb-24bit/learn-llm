⚡ Jev 与 Laya：不会写字的决策模型

lesson 0013 专题 · 热点架构 System One × 传统 LLM

主人问："jev，laya 是什么，和传统 llm 模型什么区别？"
简短的回答：它们不是"更小的 LLM"，而是另一个工种——不聊天、不写字、不解释，只做选择题/打分题/判断题，一次前向出结果，每个答案自带"校准过的把握度"。品类名字叫 System One 模型（决策模型）。

一、它们是什么

输入一段状态（工单内容、用户消息、日志），输出带校准概率的结构化决策。没有"写字"这个环节，只有三种题型（两家模型完全一致）：

原语题型例子输出
choice选择题工单派给哪个部门每个选项一个概率（和为 1）
score打分题紧急程度 0~5刻度上的分布 + 期望分
noul判断题"这条消息泄露了密钥吗？"0~1 之间一个概率

类比：LLM 是"连解题过程一起写下来的考生"，Jev/Laya 是"只涂答题卡的考生"——但答题卡上每个选项都自带校准过的把握度：说 90% 就是真的 90%，不是 LLM 那种"打肿脸充胖子的 90%"。

二、为什么要发明它：生成式 LLM 被用错了地方

生产环境的例子：给工单分类，用 LLM 要花 0.5~2 秒逐字生成 "The correct category is: billing"，再让代码把 "billing" 抠出来。

  • 慢：串行逐 token 生成
  • 贵：前沿模型的价格
  • 脆：输出是字符串，要解析、可能格式炸、可能胡编
  • 置信度不可信：token 概率 ≠ "我有多大把握答对"

关键洞察（独立评论）："生产环境里的大部分 AI 工作，是穿着生成式外衣的分类器。" 为什么是现在：100ms 是产品线——低于它，AI 才能进 UI 实时交互路径（路由、审核、风控都是每次请求都过一遍的高频动作）。

三、对比传统 LLM（核心表）

维度传统 LLM（System 2）Jev / Laya（System 1）
输出字符串：什么都有可能（答案/拒绝/胡编）类型化结构值：候选值预先枚举，类型错误数学上不可能
幻觉概率分布的固有副产物输出空间里没有"编文字"的位置
生成方式自回归：逐 token，N 个 token = N 轮串行前向非自回归：一次前向并行算出所有字段
速度500ms~2 秒 / 次官方称快 40~200 倍（独立实测 7~25 倍）
成本前沿模型单价Jev：$0.042 / 百万输入 token
置信度不校准（说 90% 时实际可能只有 60% 对）校准（RLCD 直接优化"概率要诚实"）
训练预训练 → SFT → RLHF / RLVRRLCD（Reinforcement Learning for Calibrated Decisions）
定位通用大脑：聊天/写作/代码/推理专用反射：路由/分类/打分/风控/审核

具体算例（为什么快）：工单分类到 3 个候补部门——LLM 要生成 "It should go to billing"，约 6 个 token = 6 轮串行前向（每轮都要读一遍 KV Cache）；决策模型对 3 个候选项各算一个概率，一次并行给出。轮数 6 vs 1，这就是"快两个数量级"的来源之一。

「零幻觉」的准确含义：输出不可能损坏（格式/类型不会错），不等于决策是对的——它仍可能"自信地选错选项"。前者是结构保证，后者要靠微调 + 数据。

四、Jev（闭源，"第一只螃蟹"）

🏢 TypeSafe AI · 2026-09-15 发布
  • 创始人 Diogo Almeida（ChatGPT 共同发明人之一，前 OpenAI）；隐身两年；同日官宣 4000 万美元种子轮（DCVC 领投）
  • 命名：威廉·斯坦利·杰文斯（杰文斯悖论：蒸汽机效率提高 → 煤消耗反而增加）——赌的是"智能成本每降一个数量级，解锁的用例多一个数量级"
  • 架构：新模型架构 + parallel sampler（并行采样器） + RLCD 训练
  • 官方口径：同类任务"智能水平接近现有 LLM，但快两个数量级"；首页 193.6x 快 / 444.6x 便宜来自自家 4 个工作流评测（官方自己标注"预期处于现实收益高位"）；该评测 ~68% 准确率 ≈ 中档前沿模型，但便宜 40~400 倍、快 20~200 倍
  • "不会产生类型错误"是数学保证——可由一个反例证伪；目前没人拿出来
  • 局限：全闭源（无权重、无论文、无数据集），仅付费 API；跑分全自评

社区拆解（第三方观察，置信度中低）：可能并非从零训练，而是"开源 LLM + RL 微调"；"并行采样"≈ 在预先枚举的候选集合上做受限概率计算。

五、Laya（开源，几天后的复刻 + 公案）

📦 独立研究者 · Jev 爆红几天后开源
  • 作者 Nandakishor Mukkunnoth；称 2025-03 就发表过同思路工作（arXiv:2503.23303，用 RL 做概率预测），当时无人问津；Jev 爆红后在 HN 发博客
  • 全开源：HuggingFace 权重（英文检查点 ~843MB，ModernBERT 编码器）+ 数据集 + PyPI 包；3 个检查点 + 自动路由；支持 100+ 语言
  • 自报：比 Jev 快 7.8 倍；商用硬件上 32.8ms；"零成本替代专有 API"
  • 局限（官方模型卡自认 + 独立验证）：选项 >20 个明显掉分（Banking77 的 77 类：0.425 vs Jev 0.870，架构性限制——固定 ~192-256 token 预算摊给所有候选）；不微调 ≈ 随机水平；要按领域数据拟合温度做校准（校准误差 0.466 → 0.081）
  • 公案：早期工作真实且早于 Jev；Laya 模型页确实在 Jev 发布后才建。"同时发明可信；抄袭是指控，不是已证事实。"
  • 争议：HN 有人嘲讽"这不就是给 BERT 套壳"；支持者认为"工作流形态 + 校准概率 + RLCD"是新组合——本质是两代技术（判别式分类器 + 现代编码器）的辩证回归

生态速度：发布几天内就有社区魔改（VisionLaya 给 Laya 加了视觉输入）、开发者开始做 Apple Silicon（MLX）适配。

六、防忽悠指南：怎么看待这些跑分

说法现实
官网"快 193 倍"自家评测数字 + 官方自己承认是"现实收益高位"；独立口径 7~25 倍
双方跑分对比基本都自报（harness 工程 + 选样偏差问题，同 lesson 0008）
独立小测（8 任务 78 题）Jev 微平均 0.974 vs Laya 0.590——Jev 质量仍领先；小模型在判断题上常塌到 0.5~0.7（赌硬币）
核心卖点"校准"尚无第三方验证过
方向本身被公认是真的：分类/路由/审核不该用生成式模型写小作文

七、和已学内容的连接

  • 自回归 vs 非自回归：把「KV Cache / 逐 token 解码」整套绕开——不要生成过程，轮数直接降到 1
  • 采样与温度（lesson 0010）的镜像：LLM"只输出概率分布、选词靠掷骰子"——这里把概率分布本身当产品，不掷骰子；且 token 概率 ≠ 校准概率（温度正是校准工具）
  • RLHF → RLVR → RLCD（lesson 0007）：训练目标从"讨人类喜欢"→"可验证的奖励"→"概率要诚实"，是第三类对齐目标
  • 基准课（lesson 0008）：又一例"自报跑分 vs 独立实测"
  • 产品视角：AI 应用的分层架构（快反射层 + 慢思考层）——"smart if-statement" 的定位

八、一行总结

答案

LLM 是会写字的文科生（System 2），Jev/Laya 是只举牌不解释的裁判（System 1）——不是替代，是分工；这轮新闻的真正信号不是"谁快 193 倍"，而是 AI 应用开始分层：该动脑的动脑，该反射的反射，让概率自己说话。
