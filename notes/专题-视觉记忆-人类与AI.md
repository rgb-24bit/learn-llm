# 专题：人类与 AI 的视觉记忆

**日期**: 2026-09-14
**起因**: 主人问「人类的记忆是不是能记忆视觉？现在 AI 的记忆能记忆视觉么？」
**定位**: 跨领域对照专题（认知科学 × LLM 机制）；承接阶段3 多模态（图片 Token 化 / CLIP）

---

## 一、人类的视觉记忆：三档 + "重绘"机制

| 档位 | 时长 / 容量 | 类比 |
|------|-------------|------|
| 图标记忆（瞬时） | 约 0.3 秒（不到半秒） | 闭眼后残留的"余像 / 光斑" |
| 视觉短时记忆 | 同时 3~4 件简单物体（复杂物体更少） | 脑内小白板，几秒不复习就擦掉 |
| 视觉长期记忆 | 近乎"无限"：1 万张图事后认对 83% | 相册——但存进去的不是"底片" |

- **经典实验（Standing 1973）**：1 万张照片、每张看几秒，二选一测试认对 **83%**（约 6600 张）；换成单词成绩差得多 → "图优于字"效应
- **细节 vs 大意（Brady 2008）**：把相近的同类物体放一起考（16 个同类样例），仍有 **88%** → 记住的不只是"大意"，还有可分辨的细节
- **机制关键**：大脑**不存像素**，存的是"特征 + 意义"（轮廓 / 颜色 / 情绪 / 语义）；回忆 = 按线索**重新画一遍** → 会失真、会被暗示污染（目击证词不可靠、曼德拉效应）
- 一行：**人类记视觉 = 高压缩重绘** —— 记得多、糊得快、容易被带偏

## 二、AI 的"三层记忆"与各自的视觉能力

| 层 | 类比 | 能记视觉吗 |
|----|------|-----------|
| 权重（参数里） | 画家的手艺 | 认得"猫长什么样"、能画；但记不住"你上周发的那张图" |
| 上下文 / KV Cache | 桌上摊开的材料 | 对话内能"看图答题"（图被切成几百个视觉 token）；关窗口 / 超长就没了 |
| 外部长期记忆 | 档案柜 + 检索员 | "现在"的关键：从"转成文字再存"进化到"存视觉本身" |

### 第三层 2025-2026 进展（真"视觉记忆"刚出现）

- **多模态长期记忆基准 MemLens**（arXiv 2605.14906）：跨会话多图对话测试；把证据图抽掉，主流模型准确率掉到 **2% 以下**（80.4% 的题需要图）→ 这类记忆真的在依赖画面本身。长上下文模型对话变长就退化；记忆增强 agent 长度稳定，但存储压缩时会丢视觉保真度
- **情景视觉记忆 EVM**（arXiv 2607.08497）：图不进对话上下文，外部存"**描述 + 标签 + 缩略图**"，需要时检索调回眼前——像档案管理员，不把画挂满办公室，而是编好目录
- **MemOCR**（arXiv 2601.21468）：反向操作——把记忆**渲染成一张图**来存，利用"图比文字省 token"，按重要程度调整字号（自适应信息密度，2D 视觉记忆）
- **安全视角 LUCID**（arXiv 2607.15657）：攻击研究能用"图片投毒"污染跨会话视觉记忆 → 侧面说明该能力已实际部署
- **产品侧现状**：ChatGPT 的"记忆"以文字条目为主；普通对话里上传的图不自动跨对话保留，要靠 Projects（项目）当文件夹持久化

## 三、人类 vs AI 对照总表

| 维度 | 人类 | 现在的 AI |
|------|------|-----------|
| 短时视觉 | 残影 0.3 秒 + 同时 3~4 件 | 对话内图片 token；关窗即忘 |
| 长期视觉 | 1 万张认对 8 成，靠重绘（会失真） | 权重里会"认/画"；精确回忆靠检索 |
| 存储方式 | 压缩成概念，回忆时重画 | 文字转述（丢细节）或视觉向量 / 缩略图（新） |
| 特点 | 记得多、糊得快、易被暗示 | 检索准、理解浅、不会主动"想起来" |
| 遗忘 | 遗忘曲线，需要复习 | 不主动遗忘（除非删数据）；记什么由预算决定 |

## 四、一行总结

人类是"压缩 + 重绘"的画家（记得多但会失真）；AI 过去只会"看图写小作文"，现在刚开始学会当"存画的档案员"——离像人一样主动回想画面细节，还差得远。
