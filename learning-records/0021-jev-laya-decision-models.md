# 0021: Jev 与 Laya 决策模型（专题）

**日期**: 2026-09-22
**来源**: 主人自发提问——"jev，laya 是什么，和传统 llm 模型什么区别？"（背景：9/15 TypeSafe 发布 Jev，几天后开源 Laya 出现，是本周 AI 圈最热话题）
**产出**: notes/专题-Jev-Laya-决策模型.md + lessons/0013-jev-laya-decision-models.html

## 关键要点

- 新品类「决策模型 / System One」：不生成文本，输出"带校准概率的结构化值"；三原语 choice（选择）/ score（打分）/ noul（判断题概率）
- vs 传统 LLM：非自回归一次前向（vs 逐 token N 轮）；输出空间预先枚举 → 类型错误不可能；校准概率（说 90% 就是 90%）vs token 概率不校准；RLCD vs RLHF/RLVR
- Jev：TypeSafe（Diogo Almeida，ChatGPT 共同发明人），$40M 种子轮（DCVC），闭源付费 API；官方 193.6x/444.6x 系自家评测上限，自认"现实收益高位"
- Laya：独立研究者几天后开源（ModernBERT，~843MB，HF+PyPI），自报比 Jev 快 7.8x、32.8ms；局限：>20 选项掉分、须微调（不微调≈随机）、须温度校准
- 独立实测：Jev 质量仍领先（78 题：0.974 vs 0.590）；现实收益 7~25x；"校准"卖点尚无第三方验证
- 公案：Laya 作者称 2025-03 已发表（arXiv:2503.23303）；"同时发明可信，抄袭未证实"
- "零幻觉"= 输出结构受约束、不可能格式损坏，**≠ 判断正确**（重要区分）
