## 关键要点

- 三件套：双向编码器（ModernBERT-large 395M / mmBERT-base 322M）+ 决策头（2 层 transformer + 选项标记打分器 + act/escalate 头，合计 421M）+ Router
- 答题机制 = **选项标记（Option Markers）**：每个选项挂 [MASK] 打分位 → 一次前向读全卷 → 同题选项 softmax → 概率；**选项空间请求时定义 → 新 schema 不重训**
- 预算分割：head_max_len（选项）192/256 vs 状态预算 320/768
- RLCD 训练：严格真评分规则（log + 球面 + RPS）作奖励 + logits 高斯噪声探索 + REINFORCE/组均值基线（GRPO 式）——"诚实最优"是奖励设计的数学后果
- 校准：按（题型 × 选项数）拟合温度，ECE 0.466 → 0.081
- Router：字符集检测 <0.5ms；英文模型看高棉语 = 0.000 acc / 0.952 conf（置信度不能当安全网）
- 边界：77 选项每项 3~4 token 崩（0.425 vs 0.870）；零样本≈随机；score 最弱（SST-5 0.372）；根仓库仅英文
- 性能（T4）：32.8~39.5ms/题；批量 7.2ms/题；比 Jev（236–276ms p50）快 ~7.8x
